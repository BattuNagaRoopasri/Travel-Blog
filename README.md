## 🌍 Project Overview

**Travel Blog** is a static website designed to showcase scenic destinations, personal travel stories, helpful travel tips, and vibrant galleries. It's built using HTML, CSS, and JavaScript, making it visually appealing, responsive, and perfect for any travel enthusiast or aspiring blogger.

---

## 🗺️ Features

- 🧭 **Home Page** with introduction and featured destinations
- 📖 **Travel Stories** to share personal experiences
- 🗺️ **Interactive Map** Page to explore destinations, locations, and travel routes visually
- 🌆 **Image Gallery** with JavaScript-enhanced interaction
- 📌 **Travel Tips** for smart and safe journeys
- 📝 **Contact Form** for visitor messages
- 🔍 **About Page** to introduce the blog creator
